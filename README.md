# turkey-pics-landing

Лендинг для [Turkey Trip 2026](https://github.com/xx-arteeem-xx/turkey-pics-app) — семейного приложения для сброса фоток с поездки в общий Яндекс.Диск.

Чистый статический сайт: HTML/CSS/JS, без сборки и без бэкенда. Публикуется через GitHub Pages.

## Локальный просмотр

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Публикация

Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.

## APK

`downloads/turkey-trip-2026.apk` — стабильный релиз, на него ведёт главная кнопка «Скачать приложение». `downloads/turkey-trip-2026-beta.apk` — бета (отдельное Android-приложение, свой `applicationId`, ставится рядом с prod и не трогает его), ссылка только в разделе «Разработчику». Имена файлов фиксированные, ссылки в `index.html` их не меняют.

Оба файла и `downloads/version.json` обновляются **скриптом** из репозитория приложения:

```
# из корня turkey-pics-app
tools/release.sh beta   # собрать бету и разложить на лендинг
tools/release.sh prod   # собрать prod и разложить на лендинг
```

Руками файлы в `downloads/` не трогать.

### version.json

```json
{
  "prod": { "updatedAt": "2026-09-02T16:13:08Z", "url": "https://.../turkey-trip-2026.apk", "sizeBytes": 21531708 },
  "beta": { "updatedAt": "2026-09-02T16:11:18Z", "url": "https://.../turkey-trip-2026-beta.apk", "sizeBytes": 21531720 }
}
```

Два независимых потребителя:
- **Приложение** (`UpdateChecker` в turkey-pics-app) сверяет `updatedAt` своего канала со своей датой сборки и показывает баннер «вышла новая версия» — строго по дате, не по имени файла или versionName (сам apk по тому же пути мог быть просто перезалит).
- **Сама страница** (`js/main.js`) подтягивает оттуда же размер файла и дату сборки для текста под кнопками скачивания — руками их больше не вписываем, значения не расходятся с реальными файлами.

## Из чего сделано

- Дизайн — 1:1 токены из тёмной темы приложения (`beach_theme.dart`): цвета, стеклянные карточки, градиентные pill-кнопки, тайминги анимаций появления.
- Планета в хиро-секции — [globe.gl](https://github.com/vasturiano/globe.gl) (CDN), полёт Новосибирск → Гёйнюк с дугой и зумом на весь земной шар.
- Галерея — публичный API Яндекс.Диска (`GET /v1/disk/public/resources`) по `public_key` уже публичной ссылки на альбом. Токен приложения нигде не используется.
